# Lead-Mailing: Firma einrichten (keine Code-Änderung nötig)

Pro Firma (oben „Firma“ wählen, z. B. June Fund GmbH) eintragen:

- **Absender-Adresse:** eine Adresse auf der bei Resend verifizierten Subdomain, z. B. `karriere@bewerbung.june-fund.com` (für IT-Agentur: `info@bewerbung.it-agentur.solutions`). Die Domain muss exakt der in Resend als „Verified“ angezeigten entsprechen.
- **Absender-Name:** echter Ansprechpartner, z. B. „Luisa Welken – June Fund“. Kein „noreply“.
- **Homepage-Link:** die Landingpage der Firma, z. B. `https://june-fund.com`.
- **Calendly-Link:** euer Termin-Link (optional; sonst Zeile im Text entfernen).
- **Tageslimit:** bei 50 lassen (neue Domain, Warm-up).
- **Betreff/Text:** Vorlage kann so bleiben; Platzhalter {Vorname}, {Firma} usw. werden automatisch ersetzt.
- Weiter unten: **Signatur** ausfüllen, dann **Speichern**.
- **„Versand pausiert“** erst ausschalten, wenn eine Testmail an eure eigene Gmail-Adresse über das Postfach gut ankam.

Danach für jede weitere Firma mit verifizierter Domain wiederholen. Firmen ohne Eintrag erscheinen im Postfach nicht als Absender.
